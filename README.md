# PDF Редактор для Windows

Настольный редактор PDF: Python + PySide6 (Qt 6) + PyMuPDF.

## Запуск

1. Установить Python 3.9–3.13 с python.org (галочка «Add python.exe to PATH»).
2. Двойной клик по `run.bat` — он поставит зависимости и откроет программу.
   Или вручную: `pip install -r requirements.txt` → `python pdf_editor.py [файл.pdf]`.

## Сборка .exe

`build_exe.bat` → получится `dist\PDFEditor.exe` (~70–90 МБ, Python на целевой машине не нужен).
Если хочется быстрее запуск — замените в батнике `--onefile` на `--onedir`.
Чтобы открывать PDF двойным кликом: ПКМ по PDF → «Открыть с помощью» → PDFEditor.exe.

## Возможности

**Текст**
- `T` Текст — щелчок → ввод текста (кириллица, шрифт, размер, цвет, жирный/курсив)
- `E` Изменить текст — щелчок по строке → правка/удаление; шрифт, размер и цвет подбираются по оригиналу
- `Ctrl+H` Найти и заменить — по всем страницам или по текущей

**Пометки** (правый клик по пометке — удалить)
- `M` Маркер, `R` Рамка, `P` Карандаш; цвет и толщина — на панели

**Содержимое**
- `D` Стереть область — реально удаляет текст/картинки/графику под выделением и закрашивает белым
- `I` Картинка — выделить область → выбрать файл (пропорции сохраняются)

**Страницы** (выделение в панели слева, Ctrl/Shift — несколько)
- Перестановка перетаскиванием миниатюр или `Ctrl+↑/↓`
- Поворот `Ctrl+L`/`Ctrl+R`, удаление `Ctrl+Del`, пустая страница
- Вставка из PDF или картинок (`Ctrl+I`) — объединение файлов, добавление сканов
- Сохранение выбранных страниц в отдельный PDF (разделение)

**Прочее**
- Отмена/повтор `Ctrl+Z`/`Ctrl+Y` (25 шагов)
- Масштаб `Ctrl+колесо`, по ширине `Ctrl+1`, страница целиком `Ctrl+0`
- Колесо у края страницы листает дальше; `PgUp/PgDown`
- PDF с паролем; перетаскивание файла в окно
- Сохранение атомарное (через временный файл), шрифты урезаются до использованных символов

## Ограничения (честно)

- **Правка существующего текста — это «удалить строку + написать новую»**, а не правка внутри шрифта.
  Шрифт подбирается из системных (Arial / Times New Roman / Courier New) по признакам оригинала,
  поэтому фирменные шрифты будут заменены ближайшим аналогом. Смешанное форматирование в строке
  (одно слово жирным) превратится в единое — по первому фрагменту строки.
- Текст не переносится: если новая строка длиннее старой — она может налезть на соседний текст,
  если короче — останется пробел (например, «Василёк »).
- Сканы — это картинки: «Изменить текст» и поиск там не работают. Обход: «Стереть область» + «Текст».
- Поиск без учёта регистра.
- Отмена хранит копии документа в памяти: на PDF в сотни мегабайт это заметно ест RAM.
- Заполнение PDF-форм и электронные подписи не поддерживаются. После правки документа
  существующая цифровая подпись станет недействительной — это свойство формата PDF.
